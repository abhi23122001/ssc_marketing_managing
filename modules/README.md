# modules — SHAH AI Marketing Management System

## Purpose

This directory holds the 10 requested modules of the SHAH AI Marketing
Management System. Each module is a self-contained folder containing:

- `README.md` — module purpose, workflow, inputs, approval boundary, outputs.
- Related templates, scripts, or data live under `shared/` and
  `modules/<number>-<name>/`.

## How to read a module

1. Open `modules/<number>-<name>/README.md` for that module.
2. Use the shared templates in `shared/templates/` for briefs, drafts, QA,
   and approval.
3. Keep drafts in that module folder; publish only after an approval record
   exists in `modules/09-content-approval-publishing-workflow/`.

## Rules

- Never publish, schedule, send, message, contact, or spend without an
  explicit approval record.
- Never invent clients, projects, certifications, equipment, accuracy,
  results, testimonials, prices, or contact details.
- Technical and survey-accuracy claims require qualified SSC review.
