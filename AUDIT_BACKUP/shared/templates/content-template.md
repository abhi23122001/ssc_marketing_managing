# Shared template — Content draft

Use this template for every piece of content. Keep drafts marked as
`status: DRAFT` with `approval_required: yes`.

## 1. Objective

Why are we making this? (one sentence)

## 2. Target audience

Who is it for? (e.g. EPC contractors, mining teams, solar developers)

## 3. Hook / headline

One strong line that matches the platform tone.

## 4. Main message

The core value in 2-4 lines. Explain the value of survey data: planning,
measurement, documentation, decision support, and site coordination.

## 5. Proof required

What would make this claim solid? (owner-confirmed facts, research,
technical review) Do not invent proof.

## 6. Draft

### English draft
Write the copy here.

### Hindi draft *(optional)*
Write the copy here.

## 7. CTA

Low-pressure call to action. Example: request a discussion, share project
requirements, request a quotation. Never invent contact details.

## 8. Visual / shot list

What should the viewer see? (owned footage, approved photos, or AI
illustrative visuals clearly labeled)

## 9. Review notes

Unverified or technical claims needing SSC review.
