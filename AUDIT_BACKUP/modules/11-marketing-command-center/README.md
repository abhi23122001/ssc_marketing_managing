# Module 11 - Unified Marketing Command Center

## Purpose
This module is the single entry point for the SHAH AI marketing studio.
It gives the team a clear, navigable dashboard of every existing marketing
module (01-10), the current status of each module, and the content workflow.

It is **read-only** with respect to project data and makes no external
network, API, or paid-service calls.

## Files
- `README.md`            - this file
- `Start-SHAI-Command-Center.ps1` - Windows PowerShell launcher
- `scripts/Command-Center.py`     - dashboard / module navigation

## Launch
```powershell
# from the project root
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1 dashboard
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1 status
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1 modules
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1 workflows
PS> .\modules\11-marketing-command-center\Start-SHAI-Command-Center.ps1 reports
```
