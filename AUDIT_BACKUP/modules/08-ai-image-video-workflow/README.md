# Module 08 — AI Image and Video Creation Workflow

## Purpose

A controlled workflow for AI-generated illustrative media and simple video
assembly. It defines prompt guidance, asset labeling, and quality checks
so AI visuals are never presented as documentary project evidence.

## What this module produces

- Prompt library for illustrative visuals.
- Asset labeling rules.
- Simple media assembly guidance (free/OSS tools).
- QC checklist for AI visuals.

## Inputs

- Approved/owned footage and images in `media/`.
- Free/OSS media tools (e.g., ffmpeg, GIMP, Inkscape).
- Owner-approved AI image/video provider (external service choice is
  delegated to the owner).

## Approval boundary

- AI-generated visuals are labeled "AI-generated illustrative media" and
  are never presented as project evidence.
- Prefer original SSC footage and approved photos.
- Do not remove watermarks or imitate protected brand identities.
- No external account or paid service is added by this module.

## Draft output format

- Prompt library (illustrative only).
- Shot/sequence notes using existing media.
- Labeling and QC checklist.

## Quick workflow

1. Select owned or approved media.
2. Generate illustrative visuals with a provider chosen by the owner.
3. Label outputs clearly.
4. Assemble simple video with free tools (or owner's provider).
5. Run the QC checklist and save as a draft.
