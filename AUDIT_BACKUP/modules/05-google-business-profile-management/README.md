# Module 05 — Google Business Profile Management

## Purpose

Local SEO and Google Business Profile (GBP) support for SHAH AI around
Singrauli, Waidhan, and Madhya Pradesh. It provides audit checklists, service
descriptions, post drafts, review drafts, and review-response templates —
always draft-only and never modifying the live profile without explicit owner
approval.

## What this module now contains

| File | Purpose |
|---|---|
| `data/gbp-audit-checklist.csv` | GBP audit checklist (template) |
| `data/content-calendar.csv` | Planning calendar (shared) |
| `data/instagram-library.csv` | Cross-platform content ideas |
| `shared/templates/content-template.md` | GBP post / service description draft |
| `shared/templates/qa-checklist.md` | Public-content QA checklist |

## GBP audit checklist (template)

| Category | Item | Status (template) |
|---|---|---|
| Business profile | Local service keywords (Singrauli / Waidhan / MP) | Template |
| Business profile | Category selection (current) | Template |
| Business profile | Service descriptions (review & update as needed) | Template |
| GBP posts | Post schedule and draft state | Template |
| Reviews | Response drafts (paid/premium review requests) | Template |
| Local SEO | Location relevance (Singrauli / Waidhan / MP) | Template |

## Local SEO and category recommendations

- Use local keywords only where relevant: Singrauli, Waidhan, Madhya Pradesh.
- Keep UKG service descriptions natural and non-claim-heavy.
- Do not add review requests, offers, hours, or locations that are not confirmed.

## Approval boundary

- Never fabricate reviews, offers, hours, or locations.
- Do not publish or post on the live GBP profile without explicit owner approval.
- GBP content must not claim unconfirmed business details.

## Quick workflow

1. Audit the profile using `data/gbp-audit-checklist.csv`.
2. Draft service descriptions and GBP post drafts.
3. Draft review responses.
4. Run the QA checklist.
5. Obtain owner approval before any live profile change.
