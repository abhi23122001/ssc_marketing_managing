# Module 10 — Analytics and Monthly Reporting

## Purpose

A reporting module for SHAH AI to structure monthly results using only
metrics the owner supplies or an explicitly connected, authorized source
confirms. It keeps reporting disciplined and avoids invented reach,
leads, engagement, conversion, or ROI.

## What this module produces

- Monthly report skeleton.
- KPI definitions and metric definitions.
- Trend templating for owner-supplied data.
- A clear "missing data" section.

## Inputs

- Metrics supplied by the owner.
- Explicit connected, authorized data sources only (if any).
- Date range and platform names.
- Note: this module does not generate metrics or fabricate performance.

## Approval boundary

- No invented metrics. Every number must trace to supplied or confirmed
  data.
- Do not publish owner data without approval.

## Draft output format

A monthly report with:

- Date range and platforms covered
- KPI definitions
- Summary tables (owner-supplied numbers)
- Insights and next steps
- Missing-data list (what was not available)

## Quick workflow

1. Collect owner-supplied metrics.
2. Define KPIs (stated clearly).
3. Fill the skeleton table.
4. State date range and metric definitions.
5. List missing data.
6. Save as a draft and review with the owner.
